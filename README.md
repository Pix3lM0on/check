# Check!
`check` is a command-line tool to... check. That's literally the name. To check stuff.

## Example usage
- `check cpu temp` - displays CPU temperature info
- `check cpu usage` - displays CPU usage including average and per core
- `check ram usage` - displays RAM usage percentage and usage in MiB
